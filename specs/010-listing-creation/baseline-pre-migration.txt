## Section D — Existing `listings.*` permission keys
## Source: SELECT key FROM public.permissions WHERE key LIKE 'listings.%' ORDER BY key
================================================================================

5 rows (the Phase 6 inventory; Phase 10 reuses these unchanged per FR-008 / R-15):

```
listings.approve
listings.delete_any
listings.edit_any
listings.reject
listings.view_all
```

Note absent (intentionally): `listings.create`, `listings.edit_own`, `listings.delete_own`.
Per FR-008 + R-15, write permissions for the publisher's own listing are gated
by the `publisher_status='approved'` profile column + the listing's
`publisher_id = auth.uid()`, NOT by a permission key. This is the three-layer
enforcement model (UX tile, router guard, RLS).

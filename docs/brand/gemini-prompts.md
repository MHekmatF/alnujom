# Alnujom — Gemini / Nano Banana prompt pack (whole identity)

How to use every prompt below:
1. **Attach** your clean logo (`docs/brand/logo/logo_towers_cut.png` *or* `logo_emblem_cut.png`)
   as the style/brand reference. Optionally also attach a Pinterest ref you like.
2. **Brand colors** (always): navy `#0E1A2E`, royal blue `#1F4FE6`, steel/silver `#9AA4B2`,
   sky accent `#4D8DFF`. Premium, modern, tech-forward, real estate.
3. **Arabic rule:** Gemini breaks Arabic letters. So these prompts ask for the design with
   **English only / empty text space**. Add **النجوم للتسويق العقاري** + contact afterwards in
   Canva/Figma (or send it to me). For one-line English it's usually fine.
4. Ask for **one** high-detail result, then *edit* it ("keep this, change X").

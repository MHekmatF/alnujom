Rationale. One royal-blue accent (#1F4FE6 light / #5896FF dark) carries every interactive state — links, active tabs, prices, primary buttons — so hierarchy reads instantly and the brand feels singular, not busy. Gold is reserved exclusively for the “مميّز / Featured” badge, keeping it precious. Neutrals are a cool navy-tinted slate ramp that holds WCAG AA in both modes. Tajawal gives the Arabic UI a modern geometric warmth; Inter sets all numerals and Latin LTR (prices, areas) for clean tabular figures. Everything maps 1:1 to Material 3 — soft tinted shadows, an 8-pt grid, standard radii — so a developer rebuilds it in Flutter exactly.

# Al Nujom 1.1.1 — what changed

<!-- Three lines for the Telegram post; the same three go into latest.json. -->

- Signing in now opens the app instead of leaving you on the sign-in screen.
- Browsing as a guest no longer throws you out of the app, and the smart search
  assistant finally has a way in.
- Correct notification icon, and dates and exchange rates that read the right
  way round in Arabic.

---

## In full

**Fixed**

| What happened | What happens now |
|---|---|
| "Sign in" succeeded but the screen never changed, so it looked like it had failed | The app moves to Home the moment the session exists |
| Three of the five bottom tabs exited the app for a guest | Every tab works for a guest |
| The smart assistant existed with no route to it from the UI | It has a visible entry point |
| Notifications arrived with a blank icon and no heads-up | App icon, correct heads-up |
| The listing detail page slid under the status bar when scrolled | Opaque bar, nothing passes beneath |
| An exchange rate rendered backwards (`SYP = 0.00006 USD 1`) | Reads in the right order |
| An English date on an Arabic admin screen | Arabic dates throughout |
| Loaded photographs announced themselves to a screen reader as "unavailable"; three app-bar buttons had no name at all | Correct semantics |

**Added**

- A **privacy-policy** link and the support channels on the About page.
- The listing map no longer discloses an exact position to anyone without the
  right to see it.
- New accounts default to Arabic.

**Below the surface**

Weekly database backups, a job that finishes account deletions after the 30-day
grace period, and a permission gap closed on a coordinates function.
